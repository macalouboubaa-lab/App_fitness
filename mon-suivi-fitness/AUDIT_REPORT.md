# Audit Report

## État initial

Le projet est dans une phase de préparation. La structure de base est créée pour permettre une mise en place rapide d'une application de suivi fitness.

## Points clés

- L'application cible un parcours de 8 semaines.
- Les données doivent rester simples et faciles à maintenir.
- L'UX est prioritaire pour la motivation et le suivi.
- Les GIFs d'exercices doivent être stockés de façon cohérente.

## Recommandations

- Centraliser les données dans un fichier de logique métier.
- Séparer les composants UI des données.
- Réserver les pages dynamiques pour chaque semaine.
- Vérifier la hiérarchie visuelle avant la mise en production.
